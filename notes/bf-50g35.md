### 3. Agent Config Conversion (`src/config.rs`)
```rust
pub fn baseline_burn_rate_or_default(&self) -> crate::burn_rate::BaselineBurnRates {
    match &self.baseline_burn_rate {
        Some(config) => config.to_baseline_burn_rates(),  // Agent-specific
        None => crate::burn_rate::BaselineBurnRates::default(),  // Global defaults
    }
}
```
Returns agent-specific config or falls back to global defaults.
