## Technical Details

### Schema Discovery
The issues table uses `issue_type` (not `type`) as the column name. Key columns include:
- `id`, `title`, `description`, `status`, `priority`, `issue_type`
- `assignee`, `owner`, `created_at`, `updated_at`, `closed_at`
- `ephemeral`, `pinned`, `is_template` (filtering flags)
- `defer_until`, `due_at` (temporal filters)

### Standard Pluck Filters (Not Applied Here)
Normal Pluck operations apply these filters (this query deliberately omits them):
- `status = 'open'`
- `ephemeral = 0` (non-ephemeral only)
- `pinned = 0` (exclude pinned)
- `is_template = 0` (exclude templates)
- Exclude labels: `deferred`, `human`, `blocked`

### Query Pattern
Basic query pattern used:
```sql
SELECT COUNT(*) FROM issues;
SELECT COUNT(*) FROM issues WHERE status = 'open';
SELECT status, COUNT(*) FROM issues GROUP BY status;
```
