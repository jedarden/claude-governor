## Correct SQL Query for Ready Beads

```sql
SELECT id, title, priority
FROM issues
WHERE status = 'open'
  AND ephemeral = 0
  AND pinned = 0
  AND is_template = 0
  AND id NOT IN (
    SELECT issue_id FROM labels
    WHERE label IN ('deferred', 'human', 'blocked')
  )
  AND id NOT IN (
    SELECT issue_id FROM blocked_issues_cache
  )
ORDER BY priority DESC, id;
```

This affects:
